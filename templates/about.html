About the Project

Django Blog is a dynamic blogging platform where users can explore articles across different categories.

The website provides different categories such as Food, Sports, Technology, Health, Science, Business and Politics.

Each published blog can be opened as an individual article with its title, author, publication date, featured image, short description and complete blog content.

Technologies Used

  • Python
  • Django
  • HTML
  • CSS
  • Bootstrap
  • SQLite

Features

  • Dynamic blog posts
  • Blog categories
  • Featured posts
  • Individual blog pages
  • Dynamic featured images
  • Social media links
  • Admin panel for managing content
